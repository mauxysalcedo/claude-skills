# claude-skills

Colección de skills para Claude. Cada carpeta es una skill con su archivo `SKILL.md`.

## Skills

- [`pedidos-whatsapp-con-base-de-datos`](pedidos-whatsapp-con-base-de-datos/SKILL.md): método para montar un sistema de pedidos de una tienda pequeña (página de pedidos, base de datos en Supabase, alertas y confirmaciones por Telegram, garantías, Shopify y WhatsApp Business).
- [`inizitech-video-studio`](inizitech-video-studio/SKILL.md): fábrica de videos verticales para Inizitech: animaciones con el muñequito rosado (voz, subtítulos, efectos) y edición de clips de la dueña con subtítulos palabra por palabra. Incluye motor, pipeline y reglas de marca.
- [`inizitech-content-manager`](inizitech-content-manager/SKILL.md): gerente de contenido: mezcla de videos y carruseles, pilares, calendario día por día, días de reserva, ganchos, anuncios con presupuesto pequeño, métricas semanales, flujo de producción por chat y variedad de formatos.
